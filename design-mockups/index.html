TV Tracker — popup design gallery

Six layout directions for the same popup, each grounded in a different corner of broadcast-TV vernacular. Every design shares the same accessible foundation — the Atkinson Hyperlegible typeface, off-white/dark-ink contrast pairs (never pure black on white), generous line height and letter spacing, left-aligned text, no italics or all-caps body text, and status that's always shown with an icon and a word, never color alone. What's deliberately the same across all six

  • Atkinson Hyperlegible typeface (built for low-vision/dyslexic readability), with Verdana/Tahoma fallback if offline
  • Off-white backgrounds paired with dark-ink (not pure-black) text, or a soft warm dark background with cream text — never stark white-on-black
  • Left-aligned text only, line-height 1.5+, opened-up letter spacing, no italics, no all-caps body copy
  • Every status (aired / upcoming / hiatus / ended) is shown with an icon and a word, never color alone
  • 44px+ touch targets, visible keyboard focus outlines, and consistent positioning for repeated actions like Remove
